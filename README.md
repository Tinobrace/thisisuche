# ThisIsUche - DevOps Portfolio

🚀 **Live Site:** https://thisisuche.vercel.app

Personal DevOps dashboard showcasing projects, roadmap, and technical journey.

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- React Router
- Deployed on Vercel

## Features
- 🌙 Dark Mode
- 📱 Responsive Design
- 🎨 Modern UI
- 📊 Project Dashboard
- 🗺️ Career Roadmap

## Local Development
```bash
npm install
npm run dev
```
